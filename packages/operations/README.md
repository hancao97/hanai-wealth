# HANAI · WEALTH 冷启动与增长行动方案（4周可落地）

## 目标与定位

- 核心目标：扩大目标用户覆盖与周活（WAU），为未来订阅制预埋转化路径。
- 用户画像：A股价值投资者/工程师型投资者/数据敏感型投资者。
- 差异化：GF估值+股息分布+市场情绪的日更可视化，提供“可转发的榜单与卡片”。

## 渠道策略（先图文与长视频，短视频逐步切入）

- 小红书（主阵地-图文周更2篇）
- 内容类型：
  - 数据榜单：严重低估榜/高股息榜/行业低估热力（附简评+风险点）。
  - 使用教学：筛选器组合、详情页雷达图解读。
  - 价值观：长期主义、估值纪律、股息策略。
- 结构模板：封面图（榜单/图表截屏）→ 3个结论要点 → 方法讲解 → 风险提示 → CTA（链接+收藏转发）。
- B站（精致长视频，每2周1条起步）
- 选题：
  - 产品总览与价值（5-8分钟）。
  - 每月市场复盘与低估榜TOP10拆解（8-12分钟）。
- 视频结构：引子（痛点）→ 数据与产品演示 → 实战筛选案例 → 风险与边界 → 结尾CTA（网站链接与交流群）。
- 抖音（第3-4周开始，每周1-2条，剪B站片段为主）
- 结构：问题-数据-结论-CTA（30-60秒）。先以搬运+字幕为主，建立节奏后再原创。

## 内容生产节奏（前4周）

- 周频：
- 图文：每周2篇（小红书）。
- 长视频：第2周发布首条；第4周发布第二条（B站）。
- 短视频：第3周开始每周1-2条（抖音/小红书同款短视频）。
- 月度主题：价值低估与股息策略，产品如何辅助做“有纪律的筛选与核查”。

## 增长闭环（GitHub Pages 友好，低成本可落地）

- 链路与UTM：所有外链均携带 utm_source/utm_campaign，形成渠道对比。
- 轻量留资：
- 顶部或详情页显著按钮“加入内测/订阅更新”→ 跳转 Notion/飞书/Google Form（免后端）。
- 邮件列表（Mailchimp/ConvertKit）可选；先表单收集更轻。
- 可转发素材：
- 列表页与详情页新增“复制分享图/链接”按钮（html2canvas 导出榜单/雷达图，或直接复制带UTM链接）。
- 统计与分析：
- 嵌入 Umami/GoatCounter（静态可用）统计 PV/UV、入口页面、外链点击。
- SEO/社交预览：
- `index.html` 补充标题、描述、OG/Twitter meta；提供 `sitemap.xml` 与 `robots.txt`；自定义域名可选。

## 产品内配合（不立即实现也先规划）

- 榜单页：严重低估/高股息/行业低估 一键筛选与一键分享（`src/components/StockList.vue`）。
- 详情页：生成“估值卡片”分享图（公司名/估值/股息/PE区间）（`src/components/StockDetail.vue`）。
- 全站埋点与UTM解析（在 `src/main.js` 或路由钩子处理）。
- 顶部“加入内测/订阅”入口（`src/App.vue`）。

## 合规与风险

- 所有内容与站内显著展示“非投资建议，数据或有延迟/误差”。
- 不展示收益承诺；教育为主，展示方法与边界条件。

## 指标与复盘

- 北极星：周活UV（站点）。
- 渠道指标：小红书（阅读/收藏/转发/主页点击率）、B站（完播率/关注/外链点击）、抖音（3秒/完播率）。
- 站内指标：来源分布、按钮点击（内测/订阅）、分享按钮触发、详情页停留时长。
- 周复盘：保留“选题→数据→结果→改进”的沉淀清单。

## 4周排期（可直接执行）

- 第1周：
- 搭建统计（Umami/GoatCounter）、补充 meta/OG、表单留资入口上线。
- 小红书图文2篇：严重低估榜（当周）/高股息榜（当周）。
- 第2周：
- B站首条长视频：产品总览+两种筛选法案例。
- 小红书图文2篇：估值分布读懂+详情页雷达图教学。
- 第3周：
- 一键分享（链接/图）上线（先链接复制，图导出可第二阶段）。
- 短视频每周1-2条：从B站剪辑，投放抖音/小红书。
- 第4周：
- B站第二条：月度复盘与TOP10拆解。
- 小红书2篇：行业低估热力+股息策略周更。

## 文案/脚本模板（速用）

- 小红书标题模板：
- “本周严重低估TOP10（含股息/PE）：数据看点与风险点→自取榜单”
- “A股估值分布图：哪类更便宜？用这3个筛选法更高效”
- 长视频结构：
1) 痛点/场景 2) 产品定位 3) 实机演示（筛选→详情） 4) 两个案例 5) 风险边界 6) CTA（链接+交流群）。
- 短视频脚本：
- 0-3s：问题/结论；3-20s：数据与操作；20-50s：案例；50-60s：CTA。
